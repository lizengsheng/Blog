# 技术栈

- 框架：Astro 7 与 Astro Content Collections，静态输出适合 GitHub Pages。
- 语言：TypeScript、Astro、Markdown/MDX。
- 样式：Tailwind CSS 4 与 AstroPaper 主题变量；中文正文使用系统 CJK 字体栈。
- 内容能力：Pagefind 静态搜索、Astro RSS、Astro Sitemap、Shiki 代码高亮。
- 图片：静态 SVG favicon 和静态 PNG 社交预览图；关闭动态中文 OG 生成。
- 部署：GitHub Actions、官方 Astro Pages Action、GitHub Pages 项目站点。
- 质量检查：Prettier、ESLint、Astro check、生产构建与本地预览冒烟检查。
- 运行环境：Node.js 24（CI），pnpm 11；本地 Node.js 需满足项目声明的 `>=22.12.0`。
