# 设计文档

## 产品目标

为大模型相关岗位招聘者和技术同行提供一个内容中心，以公开文章和学习仓库展现 Li Zengsheng 在大模型后训练、Agent 与 Agentic RL 方向的技术理解和持续学习能力。

## 范围与非目标

- 保持 AstroPaper 的极简博客结构、响应式体验、深浅主题、搜索、RSS、归档、标签和无障碍能力。
- 首页只包含中文自述、社交入口、精选文章和最近文章，不改造成卡片式简历落地页。
- About 页展示已确认的姓名、教育背景、技术方向、公开邮箱与 GitHub 学习仓库。
- 首发三篇公开的“持续更新”专题提纲，不声称存在尚未完成的实验结果。
- 首版不提供评论、统计、自定义域名、简历 PDF、手机号或微信。

## 用户旅程

1. 访客从首页快速了解博客主题，并进入精选或最近文章。
2. 访客通过文章、标签、归档或搜索定位后训练、Agent、Agentic RL 内容。
3. 招聘者通过 About 页核对教育背景、技术方向和公开项目，并使用邮箱或 GitHub 联系。
4. 作者使用 Markdown 模板新增文章，推送到 `main` 后由 GitHub Actions 自动部署。

## 行为与边界

- 默认语言为 `zh-CN`，日期使用中文格式，时区为 `Asia/Shanghai`。
- 公开站点地址为 `https://lizengsheng.github.io/Blog/`；所有路径必须包含 `/Blog/` 基路径。
- 三篇首发提纲设置 `draft: false`，正文明确标注“持续更新”，并提供原始论文或官方文档链接。
- 动态 OG 图片关闭，使用静态品牌预览图，避免拉丁字体无法渲染中文标题。
- 保留原 frontmatter 数据模型，不增加新的必填字段。

## 验收标准

- 主页、文章、标签、归档、搜索、About、RSS、站点地图和 404 均可从 `/Blog/` 正常访问。
- 可见 UI 与无障碍标签无模板英文残留，品牌信息中不存在 AstroPaper 示例作者内容。
- Pagefind 能检索中文和英文技术关键词。
- 三篇首发文章公开可读，About 页仅包含经确认的个人资料。
- pnpm 的格式检查、lint、类型检查和生产构建全部通过。
